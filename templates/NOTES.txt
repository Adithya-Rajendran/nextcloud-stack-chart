   You should see your CF-Connecting-IP, not the cloudflared pod IP.

6. Run `helm test` for an automated smoke check:

   helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

WHAT'S DIFFERENT FROM GROUNDHOG2K
---------------------------------
- nginx (not Apache) reads the real client IP — no more `mod_remoteip` patch.
- CronJob ships with `concurrencyPolicy: Forbid` — no manual patch needed.
- DB migrations run as a post-upgrade Hook Job using `kubectl exec` — no
  more Multi-Attach failure on RWO Cinder.
- `helm upgrade` is a single command. There is no re-apply checklist.

See `charts/nextcloud-stack/README.md` for more.
