VERIFY CLUSTER ASSUMPTIONS
--------------------------
The chart defaults assume Canonical K8s / Cilium. Two things to confirm
on a non-default cluster:

- networkPolicy.inClusterCidrs (currently {{ .Values.networkPolicy.inClusterCidrs }}) must
  cover BOTH the pod CIDR and the Service CIDR. Find both with:
    kubectl get nodes -o jsonpath='{.items[*].spec.podCIDR}'
    kubectl cluster-info dump | grep -m1 service-cluster-ip-range
- nextcloud.web.realIp.trustedCidr (currently {{ .Values.nextcloud.web.realIp.trustedCidr }})
  should match the pod CIDR where cloudflared runs.

WHAT'S DIFFERENT FROM GROUNDHOG2K
---------------------------------
- nginx (not Apache) reads the real client IP — no more `mod_remoteip` patch.
- CronJob ships with `concurrencyPolicy: Forbid` — no manual patch needed.
- DB migrations run as a post-upgrade Hook Job using `kubectl exec` — no
  more Multi-Attach failure on RWO Cinder.
- `helm upgrade` is a single command. There is no re-apply checklist.

See README.md for more.
